# 计算智能 作业一（exercises 1–3）

本目录为 `exercises1-3` 三个实验的作业代码，全部以 MATLAB Live Script（`.mlx`）提交。

## 文件说明

| 文件 | 对应实验 | 内容 |
|---|---|---|
| `exercise_1.mlx` | 实验1 | MATLAB 矩阵与绘图基础，25 小题 |
| `fuzzy_3_答案.mlx` | 实验2 | 基于模糊推理的课程评分系统建模 |
| `cifar_10test_2_答案.mlx` | 实验3 | 基于卷积神经网络的 CIFAR-10 图像分类 |
| `scoredata.xls` | 实验2 数据 | 68 条学生成绩样本（实验2 脚本读取） |

`exercise_1.mlx` 直接沿用老师下发的模板：25 道题的标题、分节符等 XML 内容与原文件
逐字符一致，只在原有的 25 个空代码块里填入了答案代码。

开发与测试环境：MATLAB R2024b。实验2 需要 Fuzzy Logic Toolbox，实验3 需要
Deep Learning Toolbox。

## 运行方法

1. 在 MATLAB 中把当前文件夹切换到本目录（`hw1`）。
2. 打开任一 `.mlx` 文件，点击「运行全部 / Run All」。
3. 运行结束后保存文件，输出与图像即会嵌入 `.mlx` 中。

各实验的注意事项：

- **实验1**：可直接运行，约数秒完成。第 1 题代码块开头设置了 `rng(42)`，
  因此含随机数的第 3、19 题结果可复现。
- **实验2**：需保证 `scoredata.xls` 与 `.mlx` 位于同一目录（脚本也会自动到 `3-fuzzy/` 下查找）。
  运行约数十秒，末尾会生成 `chengji_opt.fis`。官方 64 条规则保持不变；调整三个输入隶属函数宽度及四个输出等级中心，并在运行时将原参数和新参数的 RMSE/MAE 放在同一批 68 条数据上对比。
- **实验3**：首次运行会自动下载 CIFAR-10 数据集（约 175 MB）到 `data/cifar-10`。
  脚本顶部的 `quickRun` 开关控制训练预算：
  - `quickRun = false`（默认）：80 个 epoch，分别在第 30、60 轮降低学习率；
  - `quickRun = true`：20 个 epoch，用于快速跑通全流程与出图。

  在 CPU 上训练耗时很长，建议使用 GPU；脚本会自动检测并报告所用设备。最佳模型现在按原有的验证准确率选取，而不是默认按验证损失选取；运行后仍输出训练和验证准确率、各类别准确率及混淆矩阵。

目前三个 `.mlx` 尚未嵌入运行结果。本机没有检测到 MATLAB；请在有 MATLAB R2024b 和相应工具箱的电脑上逐个执行「运行全部」并保存，提交前检查图表和数值均已显示。实验3 曾有一次 20 epoch 的运行记录：RTX 4060 Ti、训练准确率 85.95%、验证准确率 84.10%；这是旧配置的记录，不代表本次 80 epoch 配置的实测成绩。

## 实验2 的做法说明

模糊规则库不在 `fuzzy` 图形界面中逐条手工录入，而是先写成一张 4×4×4 的决策表
`ruleTable(期末, 实验, 出勤)`，再用三重循环展开为 64 条规则，并以断言检查
「64 种前件组合不重不漏」。这样可以从根本上避免手工录入时常见的漏填、重复与等级错位。

脚本在 68 条真实样本上给出 RMSE、MAE、最大误差与相关系数，并额外做了两项分析：

- 五种反模糊化方法（centroid / bisector / mom / som / lom）的误差对比；
- 输入隶属度函数宽度 σ 对 RMSE 的影响曲线。

此外脚本还验证了一个结论：`scoredata.xls` 中的总评列其实严格等于线性加权

```
总评 = 0.16 × 出勤 + 0.24 × 实验 + 0.60 × 期末
```

（最小二乘残差为机器精度量级）。以此为标尺，原参数的 Python 仿真 RMSE 为 2.731、MAE 为 2.202；仅调整隶属函数参数后，将相同输入的记录放在同一折、每折重新拟合参数的五折仿真得到 RMSE 2.168、MAE 1.098。该五折结果用于评估调参方法；脚本中使用的是全部 68 条记录拟合后的参数，不能把五折值视为这个最终模型的独立测试成绩。所有 MATLAB 数值以 `.mlx` 运行输出为准。误差较大的样本出现在低出勤区间：规则表对出勤差有较强惩罚，但 #12、#15、#16 三条规则仍允许总评为「中」，并非一律判「差」。该规则策略与表格中的线性加权不同。

调参仿真的可复核代码位于上一级目录的 `fuzzy_cv_repro.py`；它是分析工具，不属于 `.mlx` 作业提交文件。
