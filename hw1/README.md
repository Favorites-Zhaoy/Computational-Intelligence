# 计算智能 作业一（exercises 1–3）

本目录为 `exercises1-3` 三个实验的作业代码，全部以 MATLAB Live Script（`.mlx`）提交。

## 文件说明

| 文件 | 对应实验 | 内容 |
|---|---|---|
| `exercise_1_答案.mlx` | 实验1 | MATLAB 矩阵与绘图基础，25 小题 |
| `fuzzy_3_答案.mlx` | 实验2 | 基于模糊推理的课程评分系统建模 |
| `cifar_10test_2_答案.mlx` | 实验3 | 基于卷积神经网络的 CIFAR-10 图像分类 |
| `scoredata.xls` | 实验2 数据 | 68 条学生成绩样本（实验2 脚本读取） |

开发与测试环境：MATLAB R2024b。实验2 需要 Fuzzy Logic Toolbox，实验3 需要
Deep Learning Toolbox。

## 运行方法

1. 在 MATLAB 中把当前文件夹切换到本目录（`hw1`）。
2. 打开任一 `.mlx` 文件，点击「运行全部 / Run All」。
3. 运行结束后保存文件，输出与图像即会嵌入 `.mlx` 中。

各实验的注意事项：

- **实验1**：可直接运行，约数秒完成。开头设置了 `rng(42)`，含随机数的第 3、19 题结果可复现。
- **实验2**：需保证 `scoredata.xls` 与 `.mlx` 位于同一目录（脚本也会自动到 `3-fuzzy/` 下查找）。
  运行约数十秒，末尾会生成 `chengji_opt.fis`。
- **实验3**：首次运行会自动下载 CIFAR-10 数据集（约 175 MB）到 `data/cifar-10`。
  脚本顶部的 `quickRun` 开关控制训练预算：
  - `quickRun = true`（默认）：20 个 epoch，用于快速跑通全流程与出图；
  - `quickRun = false`：80 个 epoch，完整配置，精度更高。

  在 CPU 上训练耗时很长，建议使用 GPU；脚本会自动检测并报告所用设备。

## 实验2 的做法说明

模糊规则库不在 `fuzzy` 图形界面中逐条手工录入，而是先写成一张 4×4×4 的决策表
`ruleTable(期末, 实验, 出勤)`，再用三重循环展开为 64 条规则，并以断言检查
「64 种前件组合不重不漏」。这样可以从根本上避免手工录入时常见的漏填、重复与等级错位。

脚本在 68 条真实样本上给出 RMSE、MAE、最大误差与相关系数，并额外做了两项分析：

- 五种反模糊化方法（centroid / bisector / mom / som / lom）的误差对比；
- 输入隶属度函数宽度 σ 对 RMSE 的影响曲线。

此外脚本还验证了一个结论：`scoredata.xls` 中的总评列其实严格等于线性加权

```
总评 = 0.16 × 出勤 + 0.24 × 实验 + 0.60 × 期末
```

（最小二乘残差为机器精度量级）。以此为标尺，模糊系统在采用重心法反模糊化时
RMSE 约 2.7 分、相关系数约 0.977。二者差异最大的样本出现在出勤率极低处——
规则表中「出勤为差则总评一律为差」是一条非补偿性的一票否决策略，
而线性加权只给出勤 0.16 的权重，无法表达这种约束。这正是模糊规则相对线性模型的表达力优势。
